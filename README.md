# idkSIMULATION

Python orchestrator for combining reduced order modeling, design of experiments, and optimization workflows.

## Purpose

This project coordinates simulation-oriented AI workflows across three areas:

- ROM: surrogate and reduced order modeling
- DOE: design of experiments
- OPT: design optimization

## Installation

```bash
pip install .
```

## Status

Research and engineering framework extracted from simulation workflow experiments. The repository is public as a portfolio/reference implementation and may require environment-specific configuration.
